# Route (direction A) design sources

Artboard sources exported on 2026-09-30 from the design canvas
(https://claude.ai/artifact/JxAGFdj9yF612scQXvryDM). Direction A "Route" was
chosen; the B "Ledger" and C "Dock" artboards are rejected alternatives and are
not kept here.

| File | Artboard | Size |
|---|---|---|
| `A-Main.dc.html` | Phone run view (`project/Main.dc.html` on the canvas) | 390×844 |
| `A-Clear.dc.html` | Clear-impact bottom sheet | 390×844 |
| `A-Handheld.dc.html` | 4:3 handheld run view | 1024×768 |

The files are static mockups with inline styles. They are the visual reference
for `docs/superpowers/plans/2026-09-30-route-ui.md`. Where the brief in that
plan and these files disagree, the plan wins. Known differences:

- Fonts are linked from Google Fonts here. The client self-hosts them.
- The handheld artboard still shows an older 18px square glowing current
  marker. The current marker is the 14px round lamp from `A-Main.dc.html`,
  with no glow, on both layouts.
