# @sweep/client

The Sweep web app: an Angular 22 single-page app (standalone components, signals, Tailwind CSS 4, no SSR). It depends on `@sweep/core` (main entry only) and talks to the server over `/api`.

- Conventions, layout and package commands: [`CLAUDE.md`](./CLAUDE.md).
- Repo-wide commands (install, dev, build, lint, test): the command table in the root [`CLAUDE.md`](../../CLAUDE.md).
- End-to-end tests use Playwright: run `pnpm e2e` from the repo root.
